- V0.5 联调：前端 mock 切换为真实后端 API（Axios + JWT 拦截器），老师列表带科目、时段生成

## 遇到的问题与解决
1. **D 盘中文路径 + spring-boot:run 报 ClassNotFoundException**：mvn fork 的类路径含中文在 run 模式编码出错，改用 `mvn clean package` + `java -jar` 运行解决
2. **网络受限**：GitHub/npm 下载失败，约定走代理 127.0.0.1:7897、npm 用 npmmirror、MySQL 用阿里云镜像解决
3. **前端 mock 与真实后端字段不一致**：联调时按后端返回结构调整前端类型与映射，统一 startAt/endAt 为 ISO 字符串
