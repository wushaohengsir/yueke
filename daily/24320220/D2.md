## 遇到的问题与解决
1. **D 盘中文路径导致 spring-boot:run 报 ClassNotFoundException**：排查发现 Maven fork 的类路径含中文（短学期）在 run 模式下编码出错；改用 `mvn clean package` + `java -jar` 运行解决
2. **MySQL 间歇性掉线（Connection refused）**：重启 mysqld 恢复，数据无损；已记录启动命令备用
3. **Windows 终端 curl 发中文 JSON 返回 403**：排查发现 Git Bash 的 curl 按 GBK 发送中文，后端拒收；用 \uXXXX 转义或文件 --data-binary 验证通过，浏览器 UTF-8 不受影响——是测试环境问题而非接口缺陷
4. **git 推送 GitHub 长期失败**：原因为代理 7897 挂了但 git 配了走代理；绕过代理直连推送成功，并移除该代理配置
