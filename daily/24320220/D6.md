## 遇到的问题与解决

1. **push 被拒（fetch first）**：组长（24320213）已推送 docs 提交到 origin。解决：`git fetch origin && git rebase origin/main`，干净无冲突后双源推送成功，本组提交已位于队友提交之上（D6 两次都如此处理）。
2. **答辩要求 URL 必须为 `/about.html`**：SPA 用 createWebHistory，路由直接设 path=`/about.html`，nginx `try_files` 回退到 index 即可 200，无需物理 html 文件。
3. **本地 MySQL 中途宕掉**（3306 refused），新加 web 上下文的安全测试启动连库失败。解决：后台重启 mysqld，重跑 mvn test 转绿。
