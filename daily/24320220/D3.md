## 遇到的问题与解决
1. **前端自算日期标签存在虚假数据风险**：原 tomorrowLabel 用前端 new Date() 自算，可能与后端中国时区口径不一致。改为从后端返回的 startAt 取值，保证真实数据一致。
2. **时段模板时间带秒（18:00:00）**：数据库 TIME 字段序列化带秒，用 @JsonFormat(HH:mm) 统一去掉。
3. **推送时远程领先**：组长先推送了 D1 日报，本地落后。用 git fetch + rebase 干净合并后推送。
4. **提示词导出编码乱码**：jsonl 中文被 PowerShell 误按 GBK 读取，改用 UTF-8 显式读取 + 过滤系统提示后正确生成 txt。
